HomeLedger — a working household budget planner that runs entirely in the browser. Six pages: an Overview with the month at a glance (income, spending, what's left, savings rate), a 50/30/20 guide-vs-actual chart and budget-vs-actual bars for all twelve categories; a Planner where income sources and every category budget are editable; a Tracker that logs each expense with filters; a Goals page with progress rings, completion forecasts and an emergency-fund calculator; an Insights page with a six-month trend and advice computed from the household's own figures; and a Guide that teaches the method. It opens with one example household (a family of four in Jakarta, November 2026) whose figures agree across every page because they all derive from the same ledger. Amounts display in rupiah or US dollars, edits persist in localStorage, and every chart is SVG drawn in code. Plain static files under app/ — no build step, no framework, no network loads; it works fully offline on desktop and phone.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a browser (or open app/index.html directly)
```
